# NEAR Hackathon ecosystem logos

The organizer's [HACKATHON.md, Ecosystem section](https://nearhackathon.com/HACKATHON.md) lists these 17 ecosystem partners. The [event website](https://nearhackathon.com/#ecosystem) carries the same list. Retrieved 9 November 2026. NEAR Protocol is also displayed, using the official assets in `../near/`.

This is an ecosystem resource list; it does not establish sponsorship or endorsement of OPERRA. The strip has no visible heading, as requested. Its accessible name identifies the NEAR Hackathon ecosystem.

Original assets are bundled locally. No logos were generated. Some are official site icons accompanied by the project's name. Transparent monochrome artwork is rendered black or white to match the shared theme; other marks retain their colors.
