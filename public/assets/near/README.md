# Official NEAR artwork

Source: [NEAR Protocol's official website](https://near.org/), retrieved on 9 November 2026.

`near-symbol.svg` and `near-wordmark.svg` contain the original inline SVG artwork from the site's NEAR home link. The SVG namespace was added for standalone image use. The path geometry, viewBox, and fills are preserved.

The landing page displays both assets with their original aspect ratios. Dark mode reverses the monochrome artwork for contrast. Use of this technology attribution does not imply endorsement by NEAR.
